# Machine Learning No Supervisado

## Descripción
Este proyecto académico tiene como objetivo implementar técnicas de Machine Learning No Supervisado utilizando Python y Google Colab, explorando métodos de agrupamiento y reducción de dimensionalidad para analizar conjuntos de datos.

## Contenido del proyecto
- **K-means:** agrupamiento de datos mediante clústeres.
- **Clustering jerárquico:** identificación de grupos mediante estructuras jerárquicas.
- **PCA:** reducción de dimensionalidad mediante componentes principales.
- **SVD:** reducción de dimensionalidad mediante descomposición en valores singulares.
- **Visualización y análisis:** representación gráfica e interpretación de los resultados obtenidos.

## Herramientas utilizadas
- Python
- Google Colab
- Scikit-learn
- NumPy y Pandas
- Matplotlib y Seaborn

## Ejecución
El proyecto se encuentra en un notebook de Google Colab. Para ejecutarlo, abre el archivo `.ipynb`, ejecuta las celdas en orden y revisa las gráficas y los resultados generados.
